# DATA 606 — Statistics and Probability for Data Analytics

## Overview

This repository contains coursework for DATA 606: Statistics and Probability for Data Analytics in the M.S. Data Science program at the CUNY School of Professional Studies.

The course covers foundational statistical and probability methods used in data analytics, including probability models, sampling, statistical distributions, Bayesian statistics, and statistical techniques for categorical data.

## Topics

Coursework includes:

- Probability and statistical foundations
- Discrete probability models
- Sampling and sampling distributions
- Statistical distributions
- Bayesian statistics
- Categorical data analysis
- Statistical analysis of real-world datasets
- Data visualization
